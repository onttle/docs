# FAQ — 시작하기

## Onttle은 어떤 서비스인가요?

Onttle은 프론트엔드 개발자를 위한 가벼운 콘텐츠 인프라입니다. 테이블 스키마를 정의하면 콘텐츠를 관리하는 CMS 화면과 REST API가 바로 만들어지고, 번역·변수·파일 스토리지·Vector 검색(RAG)까지 한 곳에서 사용할 수 있습니다. 별도의 백엔드나 데이터베이스를 운영하지 않고 프론트엔드 개발에 집중할 수 있습니다.

자세한 내용은 [소개](/docs/getting-started/introduction)를 참고하세요.

## 무료로 사용할 수 있나요?

네. 신용카드 없이 Free 플랜으로 시작할 수 있으며, Free 플랜에서도 모든 Project 기능을 사용할 수 있습니다. Free 플랜에는 매월 일정량의 크레딧이 포함되고, 멤버 수·Project 수·저장 용량에 한도가 있습니다.

플랜별 한도는 [요금제와 한도](/docs/usage-and-billing/plans-and-limits)를 참고하세요.

## 어떻게 가입하나요?

이메일, Google 계정, GitHub 계정 중 하나로 가입할 수 있습니다. 이메일로 가입하면 인증 메일의 링크를 클릭해야 로그인할 수 있습니다. 처음 로그인하면 개인 Workspace가 자동으로 만들어집니다.

## 인증 메일을 받지 못했어요.

스팸함을 먼저 확인해 주세요. 메일이 없다면 로그인 화면에서 이메일과 비밀번호로 로그인을 시도한 뒤 **다시 인증 메일 보내기**를 클릭하면 인증 메일을 다시 받을 수 있습니다.

## 비밀번호를 잊어버렸어요.

로그인 화면의 **비밀번호 찾기**에서 가입한 이메일을 입력하면 재설정 링크가 발송됩니다. 링크는 재설정을 요청한 브라우저에서 열어 주세요. Google이나 GitHub로 가입했다면 해당 계정으로 로그인하면 됩니다.

## Workspace와 Project는 어떻게 다른가요?

- **Workspace**는 팀과 결제의 단위입니다. 요금제, 크레딧, 멤버를 Workspace마다 관리합니다.
- **Project**는 하나의 서비스나 웹사이트에 해당하는 단위입니다. 테이블, 번역, 변수, 파일, API Key를 Project마다 관리합니다.

하나의 Workspace에 여러 Project를 만들 수 있으며, 크레딧은 Workspace 안의 모든 Project가 함께 사용합니다.

## 첫 API 호출까지 어떻게 진행하나요?

1. Project를 만들고 Table과 Column을 추가합니다.
2. 콘텐츠를 작성하고 **발행**합니다. 발행된 콘텐츠만 API로 조회됩니다.
3. **API 키** 메뉴에서 API Key를 발급합니다. 조회만 한다면 **게시용** 키(`pk-proj_…`)로 충분합니다. 발급 직후 표시되는 전체 키를 바로 복사해 두세요.
4. `Authorization: Bearer <API Key>` 헤더로 `https://api.onttle.com/v1/{projectId}/tables/{tableId}`를 호출합니다.

단계별 안내는 [빠른 시작](/docs/getting-started/quick-start)을 참고하세요.

## 대시보드 언어를 바꿀 수 있나요?

네. 대시보드 오른쪽 위 사용자 메뉴의 **언어**에서 한국어와 English 중에 선택할 수 있습니다. 로그인한 상태에서 바꾸면 Onttle이 보내는 메일도 선택한 언어로 발송됩니다. 콘텐츠에 사용할 언어는 이와 별개로 Project 설정에서 정합니다.
