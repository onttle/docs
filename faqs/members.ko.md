# FAQ — 팀 & 권한

## 어떤 역할이 있나요?

Workspace와 Project 모두 네 가지 역할을 사용합니다.

| 역할 | 할 수 있는 일 |
| ---- | ------------- |
| 소유자 | 모든 작업. Workspace와 Project 삭제는 소유자만 할 수 있습니다. |
| 관리자 | 멤버 초대·역할 변경, 결제와 요금제 관리, Table·Column·API Key·설정 관리 |
| 편집자 | Project 생성, 콘텐츠·번역·변수·카테고리·파일·Webhook 관리, 사용량 조회 |
| 게스트 | 읽기 전용 |

자세한 권한은 [멤버 권한](/docs/developers/member-roles)을 참고하세요.

## 팀원을 어떻게 초대하나요?

**Workspace → 멤버 → 멤버 초대**에서 이메일과 역할을 입력합니다. 여러 명은 쉼표로 구분해 한 번에 초대할 수 있습니다. 이미 Onttle에 가입한 사람은 바로 멤버로 추가되고, 가입하지 않은 사람에게는 초대 메일이 발송됩니다. 소유자와 관리자만 초대할 수 있습니다.

## Google 계정이 아니어도 초대할 수 있나요?

네. 어떤 이메일 주소로든 초대할 수 있습니다. 초대받은 사람은 이메일, Google, GitHub 중 편한 방법으로 가입하면 됩니다. 다만 **초대받은 이메일 주소로 가입**해야 자동으로 Workspace에 참여합니다.

## 초대 메일의 유효 기간은 얼마인가요?

초대는 발송 후 **7일** 동안 유효합니다. 만료된 초대는 **초대 대기** 탭에서 취소한 뒤 다시 초대해 주세요.

## 멤버를 더 초대할 수 없다고 나와요.

플랜의 멤버 수 한도에 도달한 경우입니다. 한도에는 **초대 대기 중인 인원도 포함**됩니다. 사용하지 않는 초대를 취소하거나, 더 이상 필요 없는 멤버를 내보내거나, 플랜을 업그레이드해 주세요. 플랜별 멤버 수는 Free 3명, Pro 10명, Pro+ 25명, Ultra 이상 무제한입니다.

## 특정 Project에만 팀원을 참여시킬 수 있나요?

네. 먼저 Workspace에 초대한 뒤, **Project → 멤버**에서 해당 멤버를 Project에 추가하고 역할을 지정합니다. Project에는 Workspace 멤버만 추가할 수 있습니다. 외부 협업자에게는 게스트나 편집자 역할을 부여하는 것을 권장합니다.

## Workspace 소유권을 다른 사람에게 넘기려면 어떻게 하나요?

1. **Workspace → 멤버**에서 넘겨받을 멤버의 역할을 **소유자**로 바꿉니다.
2. 본인의 역할을 관리자 이하로 바꾸거나 Workspace에서 나갑니다.

Workspace에는 소유자가 한 명 이상 있어야 하므로 마지막 소유자는 역할을 바꾸거나 나갈 수 없습니다.

## 계정을 삭제하면 팀 Workspace는 어떻게 되나요?

본인이 **소유자인 Workspace는 Project, 콘텐츠, 파일과 함께 삭제**되고 구독도 해지됩니다. 다른 소유자가 있더라도 마찬가지입니다. 팀 Workspace를 남기려면 계정을 삭제하기 전에 위의 방법으로 소유권을 넘기고 본인은 소유자에서 내려와 주세요. 소유자가 아닌 Workspace는 그대로 유지되고 멤버십만 제외됩니다.
