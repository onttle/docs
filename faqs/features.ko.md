# FAQ — 기능

## 콘텐츠를 저장했는데 API에서 조회되지 않아요.

REST API는 **발행된 콘텐츠만** 반환합니다. 콘텐츠를 **저장 후 발행**하거나 목록에서 **발행**했는지 확인해 주세요. 그 밖에 다음도 확인합니다.

- **API 엔드포인트** 메뉴에서 해당 Table의 목록 조회·항목 조회 API가 활성화되어 있는지
- 요청의 Project ID와 API Key가 같은 Project의 것인지
- API Key에 허용된 호스트를 지정했다면 요청을 보내는 사이트가 목록에 있는지

## 게시용 키와 시크릿 키는 어떻게 다른가요?

API Key는 발급할 때 유형을 고릅니다.

- **게시용(Publishable, `pk-proj_…`)**: 조회(GET)만 할 수 있는 읽기 전용 키입니다. 허용 호스트와 함께 브라우저나 공개 웹사이트에서 사용할 수 있습니다.
- **시크릿(Secret, `sk-proj_…`)**: 콘텐츠 생성·수정·삭제, 파일 업로드, Chat·Embeddings API 호출까지 할 수 있습니다. 서버 환경 변수에만 보관하고 클라이언트 코드에 넣지 마세요.

게시용 키로 쓰기 요청을 보내면 `403 Forbidden`과 함께 시크릿 키가 필요하다는 메시지가 반환됩니다. 유형은 나중에 바꿀 수 없으니 필요하면 새 키를 발급하세요. 자세한 내용은 [인증 방식](/docs/rest-api/authentication)을 참고하세요.

## API Key 전체 값을 다시 볼 수 있나요?

아니요. 전체 키는 **생성 직후 한 번만** 표시됩니다. Onttle은 키의 해시만 저장하므로 이후에는 목록에서 접두사와 마지막 4자리(`pk-proj_abcd…wxyz`)만 확인할 수 있습니다. 키를 잃어버렸다면 새 키를 발급하고 기존 키를 비활성화하거나 삭제하세요. 키가 실제로 사용되고 있는지는 **API 키** 목록의 **마지막 사용** 열에서 확인할 수 있습니다.

## 어떤 Column 타입을 사용할 수 있나요?

텍스트, 숫자, 날짜, 타임스탬프, 불리언, 이메일, URL, 색상, 파일, 에디터, 카테고리, 참조 타입을 사용할 수 있습니다. 텍스트와 에디터는 다국어 값을 저장할 수 있고, 대부분의 타입은 여러 값을 배열로 저장할 수 있습니다.

Column 타입은 만든 뒤에 바꿀 수 없으니 신중하게 선택해 주세요. 자세한 내용은 [Column 타입](/docs/developers/column-types)을 참고하세요.

## 다국어 콘텐츠는 어떻게 관리하나요?

Project 설정에서 사용할 언어(한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어)와 기본 언어를 정합니다. Column에 **다국어 지원** 옵션을 켜면 언어마다 값을 입력할 수 있고, API 응답에는 언어 코드를 키로 하는 객체로 반환됩니다.

UI 문구처럼 키-값으로 관리하는 텍스트는 [번역](/docs/core-features/translations) 기능을 사용하세요. **AI로 채우기**로 다른 언어 값을 자동으로 채울 수도 있습니다.

> Project에서 언어를 제거하면 그 언어로 입력한 콘텐츠도 삭제됩니다.

## 이미지는 어떻게 제공되나요?

업로드한 파일은 저장소에 보관되고 API 응답에는 일정 시간 동안 유효한 서명된 URL(`presigned_url`)로 제공됩니다. 이미지는 업로드할 때 크기별 썸네일이 자동으로 만들어집니다. 썸네일 크기는 **파일 → 파일 썸네일 설정**에서 바꿀 수 있으며, 바꾼 설정은 이후 업로드하는 파일부터 적용됩니다.

API 응답의 URL은 짧은 시간 뒤 만료되므로 URL을 저장해 두지 말고 필요할 때 API로 다시 받아 주세요.

## 파일은 어떤 크기까지 올릴 수 있나요?

파일 한 개의 최대 크기는 플랜에 따라 Free 10 MB, Pro 100 MB, Pro+ 이상 500 MB입니다. Workspace 전체 파일 저장 용량도 플랜마다 정해져 있습니다. 대시보드에서는 한 번에 최대 200개까지 업로드할 수 있습니다.

## 이미지나 PDF의 텍스트를 추출할 수 있나요?

네. 업로드할 때 **OCR 텍스트 추출**을 선택하면 이미지와 PDF에서 텍스트를 추출해 저장합니다. **AI로 키워드와 설명 생성**을 함께 선택하면 파일의 키워드와 요약도 만들어집니다. 추출한 텍스트는 Vector 검색에도 활용됩니다. OCR과 AI 생성은 크레딧을 사용합니다.

## 변수(Variables)는 언제 사용하나요?

연락처 이메일, 공지 문구, 기능 플래그처럼 코드 배포 없이 바꾸고 싶은 설정값을 관리할 때 사용합니다. `GET /variables`로 조회할 수 있고, 콘텐츠나 번역 안에 `{{var_키}}` 형태로 넣으면 API 응답에서 실제 값으로 바뀝니다. 비활성화한 변수는 API로 조회되지 않습니다.

## Webhook은 언제 발송되나요?

Table에서 선택한 이벤트(생성, 수정, 삭제)가 **REST API를 통해** 발생할 때 발송됩니다. 대시보드에서 콘텐츠를 수정할 때는 발송되지 않습니다. 발송에 실패해도 자동으로 다시 보내지 않으므로, 수신 서버는 빠르게 `2xx`로 응답하고 무거운 작업은 따로 처리해 주세요.

## Vector 검색을 사용하려면 무엇이 필요한가요?

1. **벡터** 메뉴에서 Table을 **동기화**합니다. 발행된 콘텐츠의 텍스트, 카테고리, 파일 설명과 OCR 텍스트가 임베딩됩니다.
2. **API 엔드포인트**에서 해당 Table의 임베딩 검색 API를 활성화합니다.
3. `POST /tables/{tableId}/embeddings`로 의미 검색, `POST /tables/{tableId}/bm25`로 키워드(BM25) 검색 + 재정렬을 실행합니다.

콘텐츠를 수정하거나 새로 발행했다면 다시 동기화해야 검색 결과에 반영됩니다. 자세한 내용은 [Vector](/docs/ai/vector)를 참고하세요.

## 내 데이터로 답변하는 챗봇을 만들 수 있나요?

네. **에이전트** 메뉴에서 지시사항과 응답 스타일을 정한 Agent를 만들고, Chat API(`POST /chats`)에 Agent ID와 질문을 보내면 동기화된 Table 데이터를 찾아 답변합니다. 검색 방식은 의미 기반 검색(`vector`), 조건 검색(`query`), 둘을 함께 쓰는 `hybrid`(기본값), 키워드 검색 후 모델이 재정렬하는 `bm25` 중에서 고를 수 있습니다. 자세한 내용은 [Chats](/docs/ai/chats)를 참고하세요.

## TypeScript 타입을 자동으로 만들 수 있나요?

네. **TypeScript** 메뉴에서 Table마다 요청·응답 타입과 번역, 변수, 파일, 카테고리 같은 공통 타입을 확인하고 복사할 수 있습니다. Column을 바꾸면 타입도 함께 바뀝니다. OpenAPI 명세가 필요하면 Project 설정에서 YAML 파일을 내려받거나 공개 OpenAPI URL을 켜세요.

## MCP 서버를 지원하나요?

네. `https://api.onttle.com/mcp`를 Claude, Claude Code, Cursor 같은 MCP 클라이언트에 등록하면 AI가 프로젝트를 조회하고, 확인을 받은 뒤 콘텐츠·테이블·설정을 변경할 수 있습니다. Onttle 계정 로그인이나 API Key로 연결하며, 자세한 방법은 [MCP 서버](/docs/ai/mcp) 문서를 참고하세요. 대시보드 안에서는 [Ask AI](/docs/ai/ask-ai)로 같은 작업을 할 수 있습니다.

## 삭제한 콘텐츠를 되돌릴 수 있나요?

삭제한 콘텐츠는 대시보드에서 복구할 수 없습니다. 잘못된 수정은 **히스토리**에서 이전 버전으로 롤백할 수 있지만, 버전 이력과 잠금은 Pro 이상 플랜에서 제공됩니다. 중요한 콘텐츠는 **잠금**으로 보호하거나 정기적으로 CSV로 내보내 두세요.

## CMS를 우리 회사 도메인으로 쓸 수 있나요?

네. **Workspace → 도메인**에서 `cms.onttle.com` 같은 서브도메인을 추가하고 안내된 CNAME(필요하면 TXT) 레코드를 DNS에 등록하면 자동으로 검증된 뒤 그 주소로 접속할 수 있습니다. 루트 도메인(`acme.com`)은 연결할 수 없고, Pro 이상 요금제에서 Workspace당 20개까지 연결할 수 있습니다. 자세한 내용은 [커스텀 도메인](/docs/core-features/custom-domains)을 참고하세요.

## CMS의 색상과 로고를 바꿀 수 있나요?

네. **Workspace → 테마**에서 프리셋을 고르거나 라이트·다크 모드 색상, 라운드, 폰트, 밀도를 직접 지정하고 로고·파비콘·탭 제목을 올릴 수 있습니다. 저장하면 `app.onttle.com`에서 그 Workspace를 열 때와 커스텀 도메인 양쪽에 적용됩니다. Pro 이상 요금제에서 소유자와 관리자가 설정할 수 있습니다. 자세한 내용은 [커스텀 테마](/docs/core-features/custom-themes)를 참고하세요.
