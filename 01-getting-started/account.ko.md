# 계정과 로그인

Onttle 계정은 대시보드에 로그인해 Workspace와 Project를 관리하는 데 사용합니다. 외부에서 REST API를 호출할 때는 계정이 아닌 [API Key](/docs/rest-api/authentication)를 사용합니다.

이 문서를 읽고 나면 계정을 만들고 로그인하는 방법, 계정 정보를 바꾸는 방법, 계정을 삭제할 때 어떤 데이터가 함께 삭제되는지 알 수 있습니다.

---

## 회원가입

다음 세 가지 방법으로 가입할 수 있습니다.

| 방법 | 설명 |
| ---- | ---- |
| 이메일 | 이름, 이메일, 비밀번호를 입력해 가입합니다. 가입 후 이메일 인증이 필요합니다. |
| Google | Google 계정으로 바로 가입하고 로그인합니다. |
| GitHub | GitHub 계정으로 바로 가입하고 로그인합니다. |

비밀번호는 **8자 이상**이어야 하며 영문 대문자, 영문 소문자, 숫자, 특수문자를 모두 포함해야 합니다.

가입하면 서비스 약관과 개인정보 처리방침에 동의한 것으로 간주됩니다.

> 이미 가입된 이메일로 다시 가입하면 오류가 표시됩니다. 비밀번호가 기억나지 않으면 [비밀번호 재설정](#비밀번호-재설정)을 이용하세요.

### 이메일 인증

이메일로 가입하면 인증 메일이 발송됩니다.

1. 메일의 인증 링크를 클릭합니다.
2. **ONTTLE에 오신 것을 환영합니다** 화면이 열리고 자동으로 로그인됩니다.
3. **시작하기**를 클릭해 Workspace 목록으로 이동합니다.

인증하기 전에 로그인하면 인증이 필요하다는 안내와 함께 **다시 인증 메일 보내기** 버튼이 표시됩니다. 메일이 보이지 않으면 스팸함을 확인한 뒤 인증 메일을 다시 요청하세요.

### 처음 로그인하면

처음 로그인하면 다음이 자동으로 준비됩니다.

- **개인 Workspace**: `{이름}'s Workspace`라는 이름의 Free 플랜 Workspace가 만들어집니다.
- **환영 메일**: 가입한 이메일로 환영 메일이 발송됩니다.
- **대기 중인 초대**: 가입 전에 받은 Workspace 초대가 있으면 해당 Workspace에 자동으로 참여합니다. 만료된 초대는 제외됩니다.

## 로그인

로그인 화면에서 이메일과 비밀번호를 입력하거나 **Google로 로그인**, **GitHub로 로그인** 버튼을 사용합니다.

가입할 때 사용한 방법으로 로그인하세요.

---

## 비밀번호 재설정

1. 로그인 화면에서 **비밀번호 찾기**를 클릭합니다.
2. 가입한 이메일을 입력하고 **이메일 전송**을 클릭합니다.
3. 메일의 링크를 열어 **비밀번호 재설정** 화면에서 새 비밀번호를 입력합니다.

- 가입되지 않은 이메일을 입력하면 오류가 표시됩니다.
- 재설정 링크는 재설정을 요청한 브라우저에서 여는 것을 권장합니다. 다른 브라우저나 기기에서 열면 링크가 동작하지 않을 수 있습니다.

로그인한 상태라면 **계정 설정 → 비밀번호 변경**에서 현재 비밀번호를 입력하고 바로 바꿀 수 있습니다.

## 계정 설정

대시보드 오른쪽 위의 사용자 메뉴에서 계정 화면으로 이동합니다. 계정 화면은 세 개의 메뉴로 구성됩니다.

| 메뉴 | 설정할 수 있는 항목 |
| ---- | ------------------- |
| 프로필 | 이름, 소개, 프로필 사진 (최대 1 MB) |
| 알림 | 뉴스레터와 제품 업데이트 메일 수신 여부 |
| 계정 설정 | 비밀번호 변경, 계정 삭제 |

> 이메일 주소는 로그인과 알림에 사용되며 대시보드에서 바꿀 수 없습니다. 이메일을 변경하려면 [고객 지원](/support)으로 문의하세요.

### 언어와 테마

사용자 메뉴에서 대시보드 언어와 화면 테마를 바꿀 수 있습니다.

- **언어**: 한국어, English. 로그인한 상태에서 바꾸면 계정에 저장되며, Onttle이 보내는 메일도 이 언어로 발송됩니다.
- **테마**: 라이트 모드, 다크 모드, 시스템 모드

> 대시보드 언어는 Project의 콘텐츠 언어와 별개입니다. 콘텐츠 언어는 [번역](/docs/core-features/translations)과 Project 설정에서 관리합니다.

## 계정 삭제

**계정 설정 → 위험 구역 → 계정 삭제**에서 이메일 주소를 입력하면 계정이 삭제됩니다. 이 작업은 되돌릴 수 없습니다.

계정을 삭제하면 다음이 처리됩니다.

| 대상 | 처리 |
| ---- | ---- |
| 계정과 로그인 정보 | 삭제되어 더 이상 로그인할 수 없습니다. |
| Workspace와 Project 멤버십 | 모든 멤버십에서 제외됩니다. |
| 본인이 **소유자(OWNER)** 인 Workspace | Workspace와 그 안의 Project, 콘텐츠, 파일이 함께 삭제되고 구독이 해지됩니다. |
| 본인이 소유자가 아닌 Workspace | 그대로 유지됩니다. |

삭제가 완료되면 계정 비활성화 안내 메일이 발송됩니다.

> **Workspace를 남기려면** 계정을 삭제하기 전에 다른 멤버의 역할을 소유자로 바꾸고, 본인의 역할을 소유자보다 낮은 역할로 바꾸거나 Workspace에서 나가세요. 본인이 소유자로 남아 있는 Workspace는 다른 소유자가 있더라도 함께 삭제됩니다. 자세한 방법은 [Workspace와 멤버](/docs/getting-started/workspaces-and-members#소유권-이전)를 참고하세요.
