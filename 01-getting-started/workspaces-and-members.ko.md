# Workspace와 멤버

Workspace는 Project를 담는 공간이자 **요금제와 결제의 단위**입니다. 하나의 Workspace 안에 여러 Project를 만들고, 팀원을 초대해 함께 관리합니다.

```
Workspace (요금제, 결제, 크레딧, 멤버)
 ├── Project A (테이블, 번역, 변수, 파일, API Key …)
 └── Project B
```

이 문서를 읽고 나면 Workspace를 만들고, 팀원을 초대하고, 역할을 바꾸고, 소유권을 넘기는 방법을 알 수 있습니다.

---

## Workspace 만들기

처음 로그인하면 개인 Workspace가 자동으로 만들어집니다. Workspace를 더 만들려면 Workspace 목록에서 **새 워크스페이스 만들기**를 선택합니다.

| 항목 | 설명 |
| ---- | ---- |
| 이름 | Workspace 이름 |
| 아이콘 | 이미지 파일 (최대 1 MB, 선택) |
| 설명 | 선택 |
| 분야 | 개인, 스타트업, 에이전시, 회사, 교육기관, 예술, 비영리단체, 해당 없음 |
| 규모 | 1명, 2-10명, 11-24명, 25-100명, 100명 이상 |
| 요금제 | 사용할 플랜 |

- **Free 플랜**은 결제 수단 없이 바로 만들 수 있습니다. 한 계정이 만들 수 있는 Free Workspace 수에는 제한이 있습니다.
- **유료 플랜**을 선택하면 생성 과정에서 카드를 등록하고 첫 달 요금이 즉시 결제됩니다. 결제가 실패하면 Workspace는 만들어지지 않습니다.
- 결제일은 생성한 날짜를 기준으로 매월 같은 날 오전 9시(KST)입니다. 29~31일에 만들었다면 매월 28일에 결제됩니다.

요금제는 만든 뒤에도 언제든 바꿀 수 있습니다. 자세한 내용은 [요금제와 한도](/docs/usage-and-billing/plans-and-limits)를 참고하세요.

---

## Workspace 설정

**Workspace → 설정**에서 이름, 분야, 규모를 바꿀 수 있습니다. 소유자 또는 관리자 권한이 필요합니다. Pro 이상에서는 **도메인**과 **테마** 메뉴에서 [커스텀 도메인](/docs/core-features/custom-domains)과 [커스텀 테마](/docs/core-features/custom-themes)도 설정할 수 있습니다.

## 역할

Workspace와 Project는 같은 네 가지 역할을 사용합니다.

| 역할 | 설명 |
| ---- | ---- |
| 소유자 (OWNER) | 모든 권한. Workspace 삭제는 소유자만 할 수 있습니다. |
| 관리자 (ADMIN) | 멤버, 결제, 설정 관리를 포함한 대부분의 권한 |
| 편집자 (EDITOR) | Project를 만들고 콘텐츠를 편집할 수 있습니다. 멤버와 결제는 관리하지 못합니다. |
| 게스트 (GUEST) | 읽기 전용 |

Workspace 단위의 주요 권한은 다음과 같습니다.

| 작업 | 소유자 | 관리자 | 편집자 | 게스트 |
| ---- | :----: | :----: | :----: | :----: |
| 새 Project 추가 | ✓ | ✓ | ✓ | |
| 멤버 목록 보기 | ✓ | ✓ | ✓ | ✓ |
| 멤버 초대, 역할 변경, 내보내기, 초대 취소 | ✓ | ✓ | | |
| 사용량 보기 | ✓ | ✓ | ✓ | |
| 크레딧 잔액 보기 | ✓ | ✓ | ✓ | ✓ |
| 결제 수단, 추가 크레딧 구매, 요금제 변경·해지 | ✓ | ✓ | | |
| 인보이스 보기 | ✓ | ✓ | | |
| Workspace 정보 수정 | ✓ | ✓ | | |
| Workspace 삭제 | ✓ | | | |

Project 단위 권한은 [멤버 권한](/docs/developers/member-roles)에서 자세히 확인할 수 있습니다.

## 멤버 초대

**Workspace → 멤버 → 멤버 초대**에서 초대합니다. 소유자 또는 관리자 권한이 필요합니다.

1. 초대할 이메일을 입력합니다. 여러 명은 쉼표(`,`)로 구분합니다.
2. 역할을 선택합니다.
3. 필요하면 초대 메시지를 적고 초대합니다.

초대받는 사람의 가입 여부에 따라 다르게 처리됩니다.

| 초대받는 사람 | 처리 |
| ------------- | ---- |
| 이미 Onttle에 가입한 사람 | 바로 Workspace 멤버로 추가되고 알림 메일이 발송됩니다. |
| 아직 가입하지 않은 사람 | 초대 메일이 발송되고 **초대 대기** 탭에 표시됩니다. 초대받은 이메일로 가입하면 자동으로 참여합니다. |

- 초대는 **7일** 후 만료됩니다. 만료된 초대는 다시 보내야 합니다.
- **초대 대기 중인 인원도 플랜의 멤버 수 한도에 포함**됩니다. 한도에 도달하면 사용하지 않는 초대를 취소하거나 플랜을 업그레이드하세요.
- 이미 멤버이거나 초대 대기 중인 이메일은 다시 초대할 수 없습니다.

## 역할 변경과 내보내기

**Workspace → 멤버 → 참여 멤버** 탭에서 멤버의 역할을 바꾸거나 Workspace에서 내보낼 수 있습니다. 본인은 Workspace에서 나갈 수 있습니다.

Workspace에는 **소유자가 한 명 이상** 있어야 합니다. 마지막 소유자는 역할을 바꾸거나 나갈 수 없습니다.

### 소유권 이전

별도의 소유권 이전 기능은 없습니다. 다음 순서로 소유권을 넘깁니다.

1. 넘겨받을 멤버의 역할을 **소유자**로 바꿉니다. 한 Workspace에 소유자가 여러 명 있을 수 있습니다.
2. 필요하면 본인의 역할을 관리자 이하로 바꾸거나 Workspace에서 나갑니다.

> 계정을 삭제할 예정이라면 2단계까지 완료해야 Workspace가 유지됩니다. 본인이 소유자로 남아 있으면 계정 삭제 시 Workspace도 함께 삭제됩니다.

---

## Project 멤버

Project에는 해당 Workspace의 멤버만 추가할 수 있습니다. 외부 사용자를 Project에 참여시키려면 먼저 Workspace로 초대하세요.

1. **Project → 멤버**로 이동합니다.
2. Workspace 멤버를 선택하고 Project 역할을 지정해 추가합니다.

Project 멤버 관리는 Project의 소유자 또는 관리자가 할 수 있습니다. Project에도 소유자가 한 명 이상 있어야 합니다.

---

## Workspace 삭제

**Workspace → 설정 → 위험 구역 → 워크스페이스 삭제**에서 Workspace 이름을 입력해 삭제합니다. 소유자만 삭제할 수 있습니다.

- Workspace 안의 모든 Project, 콘텐츠, 파일이 함께 삭제됩니다.
- 유료 플랜의 구독은 즉시 해지됩니다. 남은 기간에 대한 요금은 환불되지 않습니다.
