# Onttle 소개

Onttle은 프론트엔드 개발자를 위한 콘텐츠 인프라 플랫폼입니다. 데이터 스키마 관리부터 자동 생성 CMS, REST API 제공까지 하나의 서비스에서 처리합니다.

별도의 백엔드 서버 없이 Onttle의 API Key 하나로 애플리케이션에 필요한 모든 콘텐츠 데이터를 가져올 수 있습니다.

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Workspace  │ ──▶ │   Project   │ ──▶ │    Table    │ ──▶ │  REST API   │
│  팀 · 결제    │     │  서비스 단위   │     │ 콘텐츠 스키마  │     │  데이터 제공   │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

---

## 주요 기능

| 기능                | 설명                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| **테이블 & 콘텐츠** | 타입이 지정된 컬럼으로 데이터 스키마를 정의하고 콘텐츠를 관리합니다       |
| **자동 생성 CMS**   | 테이블 스키마를 정의하면 콘텐츠 입력·수정·발행 화면이 자동으로 구성됩니다 |
| **REST API**        | 발행된 콘텐츠를 표준 HTTP 요청으로 즉시 사용할 수 있습니다                |
| **다국어 번역**     | 키-값 방식으로 번역 리소스를 관리하고 locale별로 조회합니다               |
| **파일 스토리지**   | 이미지와 문서를 업로드하고 최적화, OCR 추출을 제공합니다                  |
| **변수 관리**       | 환경별 설정값과 피처 플래그를 API로 제공합니다                            |
| **Webhook**         | 콘텐츠 생성·수정·삭제 이벤트를 외부 시스템에 전달합니다                   |
| **AI 기능**         | Auto-fill, 컬럼 추천, AI Ask로 콘텐츠 작업을 자동화합니다                 |
| **Vector 검색**     | 테이블 데이터를 벡터로 동기화해 시맨틱 검색을 지원합니다                  |

## 기본 사용 흐름

Onttle을 처음 시작하면 다음 순서로 설정합니다.

1. **Workspace 생성** — 팀과 결제를 관리하는 최상위 단위입니다.
2. **Project 생성** — 서비스 또는 도메인별로 데이터를 분리합니다.
3. **Table 설계** — 콘텐츠 스키마를 컬럼 단위로 정의합니다.
4. **콘텐츠 작성** — 스키마에 맞는 데이터를 입력하고 발행합니다.
5. **API Key 발급** — Project 범위에서 게시용(읽기 전용) 또는 시크릿(읽기+쓰기) 키를 발급합니다.
6. **API 호출** — `Authorization: Bearer` 헤더로 REST API를 호출합니다.

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 1. Workspace │ ──▶ │  2. Project  │ ──▶ │  3. Table    │
│     생성      │     │     생성      │     │     설계      │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                   │
                                                   ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  6. API 호출  │ ◀── │ 5. API Key   │ ◀── │  4. 콘텐츠     │
│              │     │     발급      │     │     작성      │
└──────────────┘     └──────────────┘     └──────────────┘
```

## 대시보드 사용자 vs. 외부 API 사용자

Onttle에는 두 가지 사용 주체가 있습니다.

**대시보드 사용자**

- Workspace와 Project를 생성하고 관리합니다.
- Table 스키마와 콘텐츠를 직접 편집합니다.
- 멤버를 초대하고 역할을 설정합니다.
- 사용량과 결제를 모니터링합니다.

**외부 API 사용자 (애플리케이션)**

- 발급된 API Key로 REST API에 접근합니다.
- 게시용 키로는 조회만, 시크릿 키로는 조회와 쓰기를 할 수 있습니다.
- Webhook을 통해 변경 이벤트를 수신할 수 있습니다.
