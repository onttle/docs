# 사용량과 로그 확인

Onttle은 서비스 사용량을 지표별로 기록하고, 이를 기준으로 크레딧을 차감합니다. 사용량 화면에서 어떤 기능이 크레딧을 얼마나 썼는지 확인하고, 로그 화면에서 API 요청을 하나씩 조회할 수 있습니다.

| 화면 | 위치 | 필요한 권한 |
| ---- | ---- | ----------- |
| Workspace 사용량 | **Workspace → 사용량** | 소유자, 관리자, 편집자 |
| Project 사용량 | **Project → 사용량** | 소유자, 관리자, 편집자 |
| 로그 | **Project → 로그** | 소유자, 관리자, 편집자 (Pro 이상 플랜) |

---

## 사용량

### 기간

| 선택 | 범위 |
| ---- | ---- |
| 이번 사이클 | 현재 결제 주기 시작부터 지금까지 |
| 최근 7일 | 오늘을 포함한 7일 |
| 최근 30일 | 오늘을 포함한 30일 |
| 날짜 직접 선택 | 최대 100일 |

### 보기 방식

- **묶음 기준**: 제품별(지표별) 또는 프로젝트별로 나눠 봅니다. 프로젝트별 보기는 Workspace 사용량에서 사용합니다.
- **차트 단위**: 일별, 주별, 월별, 누적

### 요약 지표

| 항목 | 설명 |
| ---- | ---- |
| 전체 사용 이벤트 | 기간 안에 기록된 사용 이벤트 수 |
| 사용한 총 크레딧 | 기간 안에 차감된 크레딧 |
| 이번 사이클 사용량 | 이번 결제 주기에 받은 크레딧 중 사용한 크레딧과 비율 |

### 측정 항목

| 항목 | 기록되는 경우 |
| ---- | ------------- |
| 데이터 저장량 | 콘텐츠, 번역, 변수를 저장할 때 |
| API 읽기 요청 | GET 요청 |
| API 쓰기 요청 | POST, PUT, DELETE 요청 |
| API 전송량 | API 응답으로 전송한 데이터 크기 |
| 웹훅 요청 | Webhook을 발송할 때 |
| 업로드 요청, 업로드 전송량 | 파일을 업로드할 때 |
| 이미지 최적화 요청 | 이미지 썸네일을 생성할 때 |
| OCR 요청 | 파일에서 텍스트를 추출할 때 |
| 생성형 AI 토큰 | Auto-fill, 추천, 텍스트로 추가 등 AI 생성 기능 |
| Ask AI 토큰 | 대시보드 AI 어시스턴트와 Chat 검색 |
| 임베딩 토큰 | Vector 동기화와 임베딩 검색 |

항목별 크레딧 단가는 [`/pricing`](/pricing) 페이지에서, 각 지표의 정의는 [지표 종류](/docs/usage-and-billing/metric-types)에서 확인하세요.

### 크레딧 잔액

크레딧 잔액은 Workspace 사이드바에서 항상 확인할 수 있습니다. 잔액이 적어지면 **크레딧이 곧 소진될 예정입니다**, 모두 쓰면 **크레딧을 모두 소진했습니다** 안내가 표시됩니다. 결제 주기별 크레딧 지급 내역은 **Workspace → 결제**에서 확인합니다.

## 로그

**Project → 로그**에서 API Key로 호출한 REST API 요청을 조회합니다. 요청이 실패한 원인을 찾거나 어떤 키가 어떤 경로를 호출하는지 확인할 때 사용합니다.

| 열 | 설명 |
| -- | ---- |
| 시간 | 요청 시각 |
| 상태 | HTTP 상태 코드 |
| 호스트 | 요청을 보낸 호스트 |
| 경로 | 호출한 API 경로 |
| 메시지 | 오류 메시지 등 |
| API 키 | 요청에 사용한 API Key |

### 필터

- **기간**: 최근 30분부터 1주일까지, 또는 날짜 직접 선택
- **상태**: 2xx, 4xx, 5xx
- **메서드**: GET, POST, PUT, DELETE
- **키워드**: 경로나 메시지에서 검색

> 로그는 **Pro 이상 플랜**에서 제공됩니다. Free 플랜에서는 요청 내용이 저장되지 않으므로, 업그레이드한 뒤의 요청부터 확인할 수 있습니다.
