# 지표 종류

Onttle은 서비스 사용량을 여러 지표로 측정하여 크레딧을 계산합니다. 각 지표가 무엇을 측정하는지, 언제 기록되는지 이해하면 비용을 예측하고 관리하기 쉬워집니다.

---

## 지표 목록

### 데이터 저장

| 지표 코드          | 지표명        | 측정 단위     | 설명                                                                                                  |
| ------------------ | ------------- | ------------- | ----------------------------------------------------------------------------------------------------- |
| `DATA_STORE_BYTES` | 데이터 저장량 | 바이트(Bytes) | 콘텐츠, 번역, 변수를 저장할 때 늘어난 데이터 크기. 저장할 때 한 번 기록되며, 늘어난 용량만 계산합니다 |

### API 호출

| 지표 코드            | 지표명        | 측정 단위     | 설명                                                                                                           |
| -------------------- | ------------- | ------------- | -------------------------------------------------------------------------------------------------------------- |
| `API_READ_CALLS`     | API 읽기 요청 | 호출 수       | Contents, Translation, Variable 등을 조회하는 GET 요청 수                                                      |
| `API_WRITE_CALLS`    | API 쓰기 요청 | 호출 수       | Contents 생성, 수정, 삭제 등의 POST/PUT/DELETE 요청 수                                                         |
| `API_WEBHOOK_CALLS`  | 웹훅 요청     | 호출 수       | Onttle이 등록된 Webhook URL로 발송한 이벤트 수. 발송 전에 잔액을 확인하며, 크레딧이 부족하면 발송을 건너뜁니다 |
| `API_TRANSFER_BYTES` | API 전송량    | 바이트(Bytes) | API 응답으로 전송된 총 데이터 크기                                                                             |

### 파일

| 지표 코드                       | 지표명             | 측정 단위     | 설명                                                                                            |
| ------------------------------- | ------------------ | ------------- | ----------------------------------------------------------------------------------------------- |
| `FILE_UPLOAD_BYTES`             | 업로드 전송량      | 바이트(Bytes) | 업로드된 파일의 총 크기. 업로드할 때 한 번 기록됩니다                                           |
| `FILE_UPLOAD_CALLS`             | 업로드 요청        | 호출 수       | 파일 업로드 요청 수. 크레딧이 차감되지 않습니다                                                 |
| `FILE_IMAGE_OPTIMIZATION_CALLS` | 이미지 최적화 요청 | 호출 수       | 이미지 최적화(리사이즈, 포맷 변환 등) 처리 수. 크레딧이 차감되지 않습니다                       |
| `FILE_OCR_CALLS`                | OCR 요청           | 페이지 수     | OCR(광학 문자 인식)로 처리한 페이지 수. 이미지 1장은 1페이지, PDF는 실제 페이지 수로 계산합니다 |

### AI

| 지표 코드               | 지표명         | 측정 단위 | 설명                                                                                 |
| ----------------------- | -------------- | --------- | ------------------------------------------------------------------------------------ |
| `AI_GENERATION_TOKENS`  | 생성형 AI 토큰 | 토큰 수   | 추천, 자동 채우기, 샘플 데이터, 번역, 키워드 생성 등 생성형 AI 기능에 사용된 토큰 수 |
| `AI_ASK_TOKENS`         | AI 질문 토큰   | 토큰 수   | 대시보드 AI 어시스턴트, Ask AI, 공개 API의 Chat, 검색 플래너·재정렬에 사용된 토큰 수 |
| `API_EMBEDDINGS_TOKENS` | 임베딩 토큰    | 토큰 수   | Vector 검색을 위한 임베딩 생성에 사용된 토큰 수                                      |

### 회원

| 지표 코드        | 지표명    | 측정 단위 | 설명                                                                                           |
| ---------------- | --------- | --------- | ---------------------------------------------------------------------------------------------- |
| `MEMBER_SIGNUPS` | 회원 가입 | 건수      | [회원 기능](/docs/core-features/members)에서 이메일 인증을 완료한 가입 건수. 로그인, 토큰 갱신, 탈퇴, 인증 메일 발송은 집계하지 않습니다 |

## 지표별 단가

사용량은 지표의 단위 크기로 올림한 뒤 단위당 크레딧을 곱해 계산합니다. 1 크레딧은 1원(부가세 포함)이며, 단가는 모든 플랜에 동일하게 적용됩니다.

| 지표                                                 | 단가                                                 |
| ---------------------------------------------------- | ---------------------------------------------------- |
| `AI_GENERATION_TOKENS`                               | 100만 토큰당 500 크레딧                              |
| `AI_ASK_TOKENS`                                      | 100만 토큰당 500 크레딧                              |
| `API_EMBEDDINGS_TOKENS`                              | 100만 토큰당 100 크레딧                              |
| `API_READ_CALLS`                                     | 1,000회당 10 크레딧                                  |
| `API_WRITE_CALLS`                                    | 1,000회당 30 크레딧                                  |
| `API_WEBHOOK_CALLS`                                  | 1,000회당 300 크레딧                                 |
| `API_TRANSFER_BYTES`                                 | 10 GB당 1,000 크레딧                                 |
| `DATA_STORE_BYTES`                                   | 1 GB당 1,000 크레딧 (저장할 때 한 번, 늘어난 용량만) |
| `FILE_UPLOAD_BYTES`                                  | 10 GB당 1,000 크레딧 (업로드할 때 한 번)             |
| `FILE_OCR_CALLS`                                     | 페이지당 10 크레딧                                   |
| `FILE_UPLOAD_CALLS`, `FILE_IMAGE_OPTIMIZATION_CALLS` | 무료                                                 |

최신 단가와 예상 사용량 기준 월 비용 계산기는 [`/pricing`](/pricing) 페이지에서 확인할 수 있습니다.

### 2026년 12월 1일부터

2026년 12월 1일 00:00 (KST)부터 AI 토큰과 저장 용량의 계산 방식이 다음과 같이 바뀝니다. 그 전까지는 위 단가가 그대로 적용됩니다.

**AI 토큰 (`AI_GENERATION_TOKENS`, `AI_ASK_TOKENS`)**

토큰 종류별 가중치를 적용한 **입력 환산 토큰** 수로 기록되고, 가중 토큰 100만 개당 **700 크레딧**이 차감됩니다.

| 토큰 종류        | 가중치 | 실제 토큰 100만 개당 크레딧 |
| ---------------- | ------ | --------------------------- |
| 입력             | ×1     | 700                         |
| 캐시된 입력      | ×0.1   | 70                          |
| 캐시 쓰기        | ×1.25  | 875                         |
| 출력 (추론 포함) | ×5     | 3,500                       |

**저장 용량**

저장할 때 한 번 차감하는 대신, 그날 저장되어 있는 용량(바이트 × 일수)을 기준으로 매일 월 단위 저장 요금이 차감됩니다.

| 지표 코드                               | 지표명                       | 단가                                            |
| --------------------------------------- | ---------------------------- | ----------------------------------------------- |
| `DATA_STORE_GB_DAYS`                    | 데이터 저장 용량             | GB·월당 800 크레딧                              |
| `FILE_STORAGE_GB_DAYS`                  | 파일 저장 용량               | GB·월당 200 크레딧                              |
| `DATA_STORE_BYTES`, `FILE_UPLOAD_BYTES` | 데이터 저장량, 업로드 전송량 | 0 크레딧 (통계용으로 사용량 화면에는 계속 표시) |

## 지표 기록 시점

| 지표                 | 기록 시점                                        |
| -------------------- | ------------------------------------------------ |
| `DATA_STORE_BYTES`   | 콘텐츠, 번역, 변수를 저장한 직후 (늘어난 용량만) |
| `API_*_CALLS`        | 각 요청이 처리된 직후 (웹훅은 발송 직후)         |
| `API_TRANSFER_BYTES` | 각 응답 전송 완료 후                             |
| `FILE_*`             | 업로드/처리 완료 직후                            |
| `AI_*`               | AI 처리 완료 직후                                |

크레딧을 사용하는 요청은 실행 전에 잔액을 확인하고, 사용량은 작업이 끝난 뒤 기록됩니다. 따라서 긴 AI 응답처럼 실제 사용량이 예상보다 크면 잔액이 0 아래로 내려갈 수 있습니다. 자세한 내용은 [구독과 크레딧](/docs/usage-and-billing/subscription-and-credits)을 참고하세요.

## 지표 확인 위치

- **대시보드**: Project → **사용량** 탭에서 기간별 지표를 그래프로 확인합니다.
- **Logs**: Project → **Logs** 탭에서 개별 API 호출 기록을 확인합니다.
- **요금**: [`/pricing`](/pricing) 페이지에서 지표별 크레딧 요금과 예상 사용량 기준 월 비용 시뮬레이션을 확인할 수 있습니다.
