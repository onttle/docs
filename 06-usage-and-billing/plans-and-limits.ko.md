# 요금제와 한도

Onttle의 요금제는 **Workspace 단위**로 구독합니다. 모든 플랜에서 테이블, 번역, 변수, 카테고리, 파일, Vector, Agent, Webhook, REST API 등 **Project 기능을 모두 사용**할 수 있으며, 플랜에 따라 한도와 일부 부가 기능이 달라집니다.

요금은 모두 **부가세(10%) 포함** 금액이며, 1 크레딧은 1원입니다. 최신 요금과 지표별 단가는 [`/pricing`](/pricing) 페이지에서 확인하세요.

---

## 플랜

| 플랜 | 월 요금 | 월간 크레딧 | 대상 |
| ---- | ------- | ----------- | ---- |
| Free | ₩0 | 1,000 | 개인 프로젝트와 간단한 실험 |
| Pro | ₩10,000 | 10,000 | API 로그, 커스텀 도메인과 테마가 필요한 소규모 팀 |
| Pro+ | ₩30,000 | 40,000 | 무제한 저장 용량이 필요한 성장하는 팀 |
| Ultra | ₩100,000 | 150,000 | 프로젝트와 멤버 수 제한 없이 운영하는 팀 |
| Enterprise | 별도 협의 | 무제한 | 맞춤 한도, 전담 지원, 세금계산서 발행이 필요한 대규모 팀 (별도 협의) |

- 월간 크레딧은 매 결제일에 플랜의 월간 크레딧으로 다시 설정되며, 남은 크레딧은 이월되지 않습니다. 모자라면 추가 크레딧(1 크레딧 = 1원)을 구매할 수 있습니다.
- 크레딧 차감과 결제 주기는 [구독과 크레딧](/docs/usage-and-billing/subscription-and-credits)을 참고하세요.

## 플랜별 한도

| 항목 | Free | Pro | Pro+ | Ultra | Enterprise |
| ---- | ---- | --- | ---- | ----- | ---------- |
| 멤버 수 (초대 대기 포함) | 1명 | 5명 | 25명 | 무제한 | 무제한 |
| Project 수 | 1개 | 5개 | 20개 | 무제한 | 무제한 |
| Project당 Table 수 | 10개 | 50개 | 200개 | 무제한 | 무제한 |
| 파일당 최대 업로드 크기 | 10 MB | 100 MB | 500 MB | 2 GB | 별도 협의 |
| Table 데이터 저장 용량 | 100 MB | 1 GB | 무제한 | 무제한 | 무제한 |
| 파일 저장 용량 | 1 GB | 20 GB | 무제한 | 무제한 | 무제한 |
| API 속도 제한 (API 키당, 초당 요청) | 5 | 20 | 50 | 100 | 100 |

- 저장 용량은 **Workspace 전체** 기준입니다. Workspace 안의 모든 Project 사용량을 합산합니다.
- 파일 한 개의 최대 크기는 플랜마다 다릅니다 (위 표 참고).
- 현재 사용 중인 저장 용량은 **Workspace → 결제**의 저장 용량 항목에서 확인할 수 있습니다.

## 한도에 도달하면

한도를 넘는 작업은 실행되지 않고 오류가 반환됩니다. 이미 저장된 데이터는 그대로 유지됩니다.

| 상황 | 오류 | HTTP 상태 |
| ---- | ---- | --------- |
| Project, Table, 멤버 수 한도 도달 | `planProjectLimitReached` 등 | 403 |
| 파일 크기나 저장 용량 초과 | `planFileSizeLimitExceeded` 등 | 413 |

대시보드에서는 한도에 도달한 기능 옆에 업그레이드 안내가 표시됩니다. 다음 중 하나로 해결합니다.

- 사용하지 않는 Project, Table, 파일, 초대를 정리합니다.
- 상위 플랜으로 업그레이드합니다. 업그레이드는 즉시 적용됩니다.

---

## 플랜을 낮추면

다운그레이드나 해지로 하위 플랜이 되어도 **데이터는 삭제되지 않습니다**. 다만 새 플랜의 한도를 넘는 상태라면 한도 안으로 줄일 때까지 새로 만들거나 올리는 작업이 제한됩니다.

예를 들어 Project가 3개인 Pro Workspace가 Free로 바뀌면 기존 Project 3개는 그대로 사용할 수 있지만 새 Project는 만들 수 없습니다.

## Enterprise

Enterprise 플랜은 계약으로 요금과 한도를 정합니다.

- 카드 자동 결제 대신 계약에 따라 청구되며, 세금계산서를 발행합니다.
- 사용량은 측정되지만 크레딧이 차감되지 않습니다. 추가 크레딧은 구매할 수 없습니다.
- 멤버, Project, 저장 용량 등의 한도는 계약에 따라 정해집니다.
- 온프레미스 설치, 사내 SSO 연동 등은 [Enterprise](/enterprise) 페이지를 참고하세요.

플랜 변경은 대시보드가 아닌 영업 담당자를 통해 진행합니다. [문의하기](/contact)에서 비즈니스 문의를 남겨 주세요.
