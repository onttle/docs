# 콘텐츠 관리

Table을 만들면 Column 구성에 맞는 콘텐츠 목록과 입력 폼이 자동으로 만들어집니다. 별도의 관리자 화면을 개발하지 않아도 이 화면에서 콘텐츠를 작성하고 발행할 수 있습니다.

이 문서를 읽고 나면 콘텐츠를 작성해 API로 공개하는 방법과, 잠금·히스토리·내보내기 등 관리 기능을 사용하는 방법을 알 수 있습니다.

> 콘텐츠를 작성하고 발행하려면 Project의 소유자, 관리자 또는 편집자 권한이 필요합니다. 게스트는 조회만 할 수 있습니다.

---

## 콘텐츠 작성

1. **Project → 테이블**에서 Table을 선택합니다.
2. 콘텐츠 추가 버튼을 클릭해 입력 폼을 엽니다.
3. Column 타입에 맞는 입력 UI에 값을 입력합니다. 필수 값, 길이, 범위 같은 Column 옵션에 맞지 않으면 저장되지 않습니다.
4. **초안으로 저장** 또는 **저장 후 발행**을 선택합니다.

Table 설정에 따라 다음 입력 항목이 함께 표시됩니다.

| Table 설정 | 추가되는 항목 |
| ---------- | ------------- |
| 콘텐츠 Slug 지원 | `slug` — API에서 ID 대신 사용할 수 있는 고유 주소 |
| SEO 지원 | `seo_title`, `seo_description`, `seo_image` |
| 다국어 지원 Column | Project에 설정된 언어마다 값을 입력하는 탭 |

> Table이 **읽기 전용**으로 설정되어 있으면 대시보드에서 콘텐츠를 편집할 수 없고 API로만 데이터를 넣을 수 있습니다.

---

## 발행

**발행된 콘텐츠만 REST API로 조회할 수 있습니다.** 초안 상태의 콘텐츠는 대시보드에서만 보입니다.

| 작업 | 결과 |
| ---- | ---- |
| 발행 | 콘텐츠가 외부에 공개되고 발행일(`published_at`)이 기록됩니다. |
| 발행 취소 | 더 이상 API로 조회되지 않습니다. 데이터는 유지됩니다. |
| 초안으로 저장 | 내용을 저장합니다. 아직 발행하지 않은 콘텐츠는 공개되지 않습니다. |

목록에서 여러 콘텐츠를 선택해 한 번에 발행하거나 발행을 취소할 수 있습니다.

### 발행 단계

목록의 발행 단계 표시로 공개 상태를 확인합니다.

| 단계 | 의미 |
| ---- | ---- |
| 발행 대기 | 아직 한 번도 발행하지 않은 콘텐츠 |
| 업데이트 필요 | 발행한 뒤 내용이 수정된 콘텐츠 |
| 최신 상태 | 마지막으로 발행한 내용과 현재 내용이 같은 콘텐츠 |

> **발행된 콘텐츠를 수정할 때 주의하세요.** 이미 발행된 콘텐츠는 초안으로 저장한 수정 내용도 API 응답에 바로 반영될 수 있습니다. 공개하지 않을 내용을 작업하려면 먼저 발행을 취소하세요.

### 상태

콘텐츠마다 작업 흐름을 나타내는 상태를 지정할 수 있습니다.

| 상태 | 설명 |
| ---- | ---- |
| 초안 (Draft) | 작성 중인 콘텐츠 |
| 검토 (In Review) | 검토 대기 중인 콘텐츠 |
| 승인 (Approved) | 승인된 콘텐츠 |
| 발행 (Published) | 발행된 콘텐츠 |
| 보관 (Archived) | 보관된 콘텐츠 |

## 잠금

콘텐츠를 잠그면 실수로 바뀌거나 삭제되지 않도록 보호할 수 있습니다.

- 잠긴 콘텐츠는 대시보드에서 편집하려면 먼저 **잠금 해제**해야 합니다.
- 잠긴 콘텐츠는 API로 수정하거나 삭제할 수 없습니다. 여러 항목을 한 번에 삭제하는 요청에서는 잠긴 콘텐츠가 제외됩니다.
- 목록에서 여러 콘텐츠를 선택해 **잠금 상태 변경**으로 한꺼번에 바꿀 수 있습니다.
- 잠금은 **Pro 이상 플랜**에서 사용할 수 있습니다. Free 플랜에서는 새로 잠글 수 없지만, 이미 잠긴 콘텐츠의 잠금 해제는 언제든 할 수 있습니다.

---

## 히스토리와 롤백

콘텐츠 입력 폼의 **히스토리**에서 이전 버전을 확인하고 현재 버전과 비교할 수 있습니다.

- 이전 버전을 선택해 **롤백**하면 그 시점의 내용으로 되돌립니다. 롤백하기 전의 현재 버전도 히스토리에 남습니다.
- 버전 이력과 롤백은 **Pro 이상 플랜**에서 사용할 수 있습니다. [요금제와 한도](/docs/usage-and-billing/plans-and-limits)를 참고하세요.

---

## 목록에서 찾기

콘텐츠 목록 위의 도구 모음에서 필터, 정렬, 검색을 사용합니다.

- **필터**: Column 타입에 맞는 조건으로 거릅니다. 예를 들어 텍스트는 포함·시작·끝, 숫자는 크기 비교, 날짜는 이전·이후·기간, 카테고리는 포함 여부로 거를 수 있습니다. 조건을 여러 개 지정하고 AND 또는 OR로 묶을 수 있습니다.
- **정렬**: 생성일, 수정일, 발행일과 정렬 가능한 Column으로 정렬합니다. 파일, 에디터, 참조 Column과 여러 값을 저장하는 Column은 정렬할 수 없습니다.
- **검색**: 콘텐츠 값에서 키워드를 찾습니다.

---

## 내보내기

목록의 **내보내기**로 콘텐츠를 CSV 파일로 내려받을 수 있습니다.

## AI로 콘텐츠 추가

| 기능 | 설명 |
| ---- | ---- |
| 텍스트로 추가 | 붙여 넣은 텍스트나 파일(txt, md, json, csv, xlsx, xls, xml, yaml, html 등)을 AI가 분석해 Column에 맞는 콘텐츠로 만듭니다. |
| 샘플 콘텐츠 추가 | Table 구조에 맞는 예시 콘텐츠를 AI가 만듭니다. 화면을 미리 구성해 볼 때 유용합니다. |
| Auto-fill | 셀, 행, Column 단위로 빈 값을 AI가 채웁니다. |

AI 기능은 생성형 AI 토큰만큼 크레딧을 사용합니다. 크레딧 차감 방식은 [지표 종류](/docs/usage-and-billing/metric-types)를, 어시스턴트로 같은 작업을 하는 방법은 [Ask AI (Assistant)](/docs/ai/ask-ai)를 참고하세요.

콘텐츠를 선택해 삭제합니다. 잠긴 콘텐츠는 먼저 잠금을 해제해야 합니다.
