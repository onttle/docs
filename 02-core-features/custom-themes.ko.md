# 커스텀 테마

커스텀 테마는 Workspace의 CMS 화면을 **팀이나 고객의 브랜드**에 맞게 바꿉니다. 색상, 모서리 라운드, 폰트, 화면 밀도와 함께 상단 바 로고, 파비콘, 브라우저 탭 제목을 설정합니다. 저장한 테마는 `app.onttle.com`에서 그 Workspace를 열 때와 [커스텀 도메인](/docs/core-features/custom-domains)으로 접속할 때 모두 적용됩니다.

| 항목 | 내용 |
| ---- | ---- |
| 요금제 | **Pro 이상** (Free에서는 메뉴가 비활성화되고 업그레이드 안내가 표시됩니다) |
| 권한 | 소유자(OWNER) 또는 관리자(ADMIN) |
| 위치 | **Workspace → 테마** |

---

## 프리셋

프리셋을 선택하면 화면이 즉시 미리보기로 바뀝니다. 색상이나 라운드를 직접 바꾸면 **커스텀**으로 전환되어 바꾼 값이 저장됩니다.

| 프리셋 | 설명 |
| ------ | ---- |
| Onttle | 기본 테마. 흑백 위주의 각진 디자인입니다. |
| 미니멀 | 차분한 회색조와 작은 라운드 |
| 다크 | 어두운 배경과 파란 포인트 색 |
| 커스텀 | 색상, 라운드, 폰트, 밀도를 직접 지정 |

---

## 색상과 스타일

### 색상

라이트 모드와 다크 모드의 색을 따로 지정합니다. 색상 선택기나 `#1d4ed8` 같은 16진수 값으로 입력합니다.

| 항목 | 쓰이는 곳 |
| ---- | --------- |
| 주요 색상 | 기본 버튼, 활성 상태, 링크 강조 |
| 주요 색상 위 글자 | 주요 색상 배경 위의 글자색 |
| 배경 | 페이지와 카드 배경 |
| 글자 | 본문 글자색 |
| 보조 배경 | 사이드바, 비활성 영역, 입력 배경 |
| 보조 글자 | 설명 문구, 비활성 글자 |
| 테두리 | 구분선, 입력 테두리 |
| 강조 배경 | 마우스를 올렸을 때, 선택된 항목 배경 |
| 경고 | 삭제 버튼과 오류 표시 |

다크 모드 색을 지정하지 않으면 선택한 프리셋의 다크 색이 사용됩니다. 주요 색상과 그 위 글자색은 대비가 충분한지 미리보기에서 확인하세요.

### 라운드, 폰트, 밀도

| 항목 | 선택지 |
| ---- | ------ |
| 라운드 | 없음(각진 모서리), 작게, 보통, 크게, 매우 크게. 버튼, 입력, 카드, 메뉴, 팝업 등 모든 요소의 모서리에 비례해서 적용됩니다. |
| 폰트 | 시스템, Inter, Pretendard, Noto Sans KR |
| 밀도 | 보통, 촘촘 (글자 크기와 간격이 줄어듭니다) |

## 브랜딩

| 항목 | 형식 | 표시 위치 |
| ---- | ---- | --------- |
| 로고 | PNG, JPG, WebP · 2 MB 이하 · 가로형 권장 | 상단 바, 로그인 화면 |
| 파비콘 | PNG 512×512 또는 ICO · 2 MB 이하 | 브라우저 탭 |
| 앱 제목 | 60자 이내 | 브라우저 탭 제목 (비우면 `Onttle`) |

로고를 지우면 Onttle 로고가 다시 표시됩니다. SVG는 업로드할 수 없습니다.

## 저장과 적용

- 변경 사항은 **저장**을 눌러야 반영됩니다. 저장하지 않고 페이지를 떠나면 확인 창이 표시됩니다.
- **되돌리기**는 마지막으로 저장한 상태로 돌아갑니다. 기본 테마로 돌아가려면 **Onttle** 프리셋을 선택해 저장하세요.
- 저장하면 바로 적용됩니다. 다른 멤버의 화면에는 다음 페이지 이동이나 새로 고침 때 반영됩니다.
- `app.onttle.com`에서는 **현재 열어 둔 Workspace의 테마**가 적용되고, Workspace를 전환하면 테마도 함께 바뀝니다. Workspace 목록, 계정 설정, `app.onttle.com`의 로그인 화면은 기본 테마로 표시됩니다.
- [커스텀 도메인](/docs/core-features/custom-domains)에서는 로그인 화면을 포함한 모든 화면에 테마가 적용됩니다.

---

## 요금제를 내리면

Free 플랜으로 바꾸면 테마 메뉴가 비활성화되어 수정할 수 없습니다. 저장된 테마는 유지되므로 다시 Pro 이상으로 올리면 그대로 사용할 수 있습니다.
