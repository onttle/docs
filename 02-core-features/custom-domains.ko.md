# 커스텀 도메인

커스텀 도메인을 연결하면 Workspace의 CMS를 `app.onttle.com` 대신 **고객이나 팀의 도메인**(예: `cms.onttle.com`)으로 접속할 수 있습니다. 에이전시가 고객에게 CMS를 넘기거나, 사내 서비스를 자사 도메인으로 운영할 때 사용합니다. 연결된 도메인에는 [커스텀 테마](/docs/core-features/custom-themes)가 함께 적용되어 로고와 색상까지 바꿀 수 있습니다.

| 항목   | 내용                                                                       |
| ------ | -------------------------------------------------------------------------- |
| 요금제 | **Pro 이상** (Free에서는 메뉴가 비활성화되고 업그레이드 안내가 표시됩니다) |
| 권한   | 소유자(OWNER) 또는 관리자(ADMIN)                                           |
| 개수   | Workspace당 최대 **20개**                                                  |
| 형식   | **서브도메인만** 가능 (`cms.onttle.com` ✓, `acme.com` ✗)                   |

---

## 도메인 추가

1. **Workspace → 도메인**으로 이동합니다.
2. 연결할 호스트명을 입력하고 **추가**를 누릅니다. 입력값은 소문자로 정리되며 `https://`나 경로는 넣지 않습니다.
3. 안내된 **DNS 레코드**를 도메인 관리 업체(가비아, Cloudflare, Route 53 등)에 등록합니다.
4. DNS가 반영되면 Onttle이 자동으로 검증하고 상태가 **활성**으로 바뀝니다. 바로 확인하려면 **DNS 설정 후 확인**을 누릅니다.

### DNS 레코드

| 타입  | 이름                    | 값               | 비고                                             |
| ----- | ----------------------- | ---------------- | ------------------------------------------------ |
| CNAME | `cms.onttle.com`        | 화면에 표시된 값 | 항상 필요합니다.                                 |
| TXT   | `_vercel.acme.com` 형식 | 화면에 표시된 값 | 도메인 소유권 확인이 필요한 경우에만 표시됩니다. |

- 값은 각 행의 **복사** 버튼으로 그대로 복사할 수 있습니다. 값 끝에 점(`.`)을 붙일 필요는 없습니다.
- 같은 이름의 A 레코드나 다른 CNAME이 이미 있다면 삭제해야 합니다. CNAME은 같은 이름에 다른 레코드와 함께 둘 수 없습니다.
- Cloudflare를 쓴다면 해당 레코드의 프록시(주황색 구름)를 **끄고** DNS only로 둡니다.

### 검증 주기

도메인을 추가하면 1분, 5분, 15분, 1시간 뒤에 확인하고, 그 뒤로는 6시간마다 최대 **72시간** 동안 다시 확인합니다. 활성화된 도메인도 매일 한 번 점검합니다. DNS 전파에는 보통 몇 분에서 길면 48시간이 걸립니다.

## 상태

| 상태          | 의미                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| DNS 설정 대기 | 레코드가 아직 반영되지 않았거나 등록되지 않았습니다. 안내된 레코드를 확인하세요.                                         |
| 활성          | 검증이 끝나 도메인으로 접속할 수 있습니다. HTTPS 인증서는 자동으로 발급됩니다.                                           |
| 오류          | 72시간 안에 검증되지 않았거나 확인 중 문제가 생겼습니다. 레코드를 고친 뒤 **DNS 설정 후 확인**을 누르면 다시 검증합니다. |

상태 아래에 표시되는 안내 문구는 다음 원인을 뜻합니다.

| 안내                                           | 원인과 조치                                                                   |
| ---------------------------------------------- | ----------------------------------------------------------------------------- |
| CNAME 레코드가 아직 Onttle을 가리키지 않습니다 | CNAME이 없거나 값이 다릅니다. 안내된 값으로 등록하고 잠시 뒤 다시 확인하세요. |
| TXT 레코드가 없습니다 / 값이 다릅니다          | 소유권 확인용 TXT 레코드를 안내된 이름과 값으로 등록하세요.                   |
| DNS 설정이 올바르지 않습니다                   | 같은 이름에 충돌하는 레코드가 있는지 확인하세요.                              |
| 72시간 안에 검증되지 않았습니다                | 레코드를 확인한 뒤 **DNS 설정 후 확인**으로 다시 시작합니다.                  |
| 도메인 연결 서비스에 문제가 있습니다           | 잠시 뒤 다시 시도하고, 계속되면 [지원](/support)에 문의하세요.                |

## 대표 도메인

도메인이 여러 개면 하나를 **대표**로 지정할 수 있습니다. 처음 추가한 도메인이 자동으로 대표가 되며, 활성 상태인 도메인만 대표로 바꿀 수 있습니다.

---

## 커스텀 도메인에서의 동작

- 커스텀 도메인은 **그 Workspace 전용**입니다. Workspace 목록, 새 Workspace 만들기, 다른 Workspace 화면은 열리지 않고 해당 Workspace로 이동합니다.
- 해당 Workspace의 멤버가 아닌 계정으로 로그인하면 접근할 수 없다는 화면이 표시됩니다.
- 로그인 화면과 상단 바에는 Workspace의 [커스텀 테마](/docs/core-features/custom-themes)(로고, 색상, 제목)가 적용됩니다.

### 로그인

- **이메일 로그인**은 커스텀 도메인에서 그대로 진행됩니다.
- **Google, GitHub 로그인**은 인증을 위해 잠시 `app.onttle.com`을 거쳤다가 커스텀 도메인으로 돌아옵니다. 돌아온 뒤 자동으로 로그인됩니다. 이 과정은 1분 안에 끝나야 하며, 지나면 로그인 화면에서 다시 시도하라는 안내가 표시됩니다.
- 로그인 세션은 **도메인마다 별개**입니다. `app.onttle.com`에 로그인했어도 커스텀 도메인에서는 다시 로그인해야 합니다.
- 비밀번호 재설정, 가입 확인 등 **이메일의 링크**는 `app.onttle.com`에서 열립니다. 처리 후 커스텀 도메인에서 로그인하면 됩니다.

## 도메인 삭제

**삭제**를 누르면 그 도메인으로는 즉시 접속할 수 없습니다. 삭제한 호스트명은 **30일 동안 다른 Workspace에서 사용할 수 없고**, 같은 Workspace에서는 바로 다시 추가할 수 있습니다.

---

## 추가할 수 없는 호스트명

| 입력                                                             | 결과                                                                        |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `acme.com` (루트 도메인)                                         | 서브도메인만 연결할 수 있습니다. `cms.onttle.com`처럼 입력하세요.           |
| `onttle.com`의 하위 도메인, `localhost`, 호스팅 업체 기본 도메인 | 예약된 호스트명이라 사용할 수 없습니다.                                     |
| IP 주소, 포트가 포함된 주소                                      | 올바른 호스트명이 아닙니다.                                                 |
| 다른 Workspace에 연결된 호스트명                                 | 이미 사용 중인 호스트명입니다. 30일 전에 삭제된 호스트명도 포함됩니다.      |
| 21번째 도메인                                                    | Workspace당 20개까지 연결할 수 있습니다. 사용하지 않는 도메인을 삭제하세요. |
