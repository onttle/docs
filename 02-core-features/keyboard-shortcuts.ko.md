# 키보드 단축키

대시보드의 주요 동작은 키보드로 실행할 수 있습니다. 전체 목록은 대시보드에서 `?` 키를 누르거나, 오른쪽 위 **프로필 메뉴 → 키보드 단축키**를 선택하면 볼 수 있습니다.

표의 `⌘`는 macOS 기준입니다. Windows와 Linux에서는 `Ctrl`을 누릅니다.

---

## 전역

| 단축키 | 동작 |
| ------ | ---- |
| `?` | 키보드 단축키 목록 보기 |
| `⌘ B` | 사이드바 접기/펴기 |
| `⌘ J` | Ask AI 패널 열기/닫기 (Project 안에서, 게스트 제외) |
| `Esc` | 열린 창 닫기, 선택한 콘텐츠·파일 선택 해제 |

---

## 이동

`G`를 누른 뒤 1.5초 안에 다음 키를 누릅니다. 두 키를 동시에 누르지 않습니다.

| 단축키 | 이동 위치 |
| ------ | --------- |
| `G` `H` | Project 홈 |
| `G` `T` | 테이블 |
| `G` `F` | 파일 |
| `G` `C` | 카테고리 |
| `G` `V` | 변수 |
| `G` `L` | 번역 |
| `G` `E` | API 엔드포인트 |
| `G` `K` | API 키 |
| `G` `U` | 사용량 |
| `G` `S` | Project 설정 |
| `G` `W` | Workspace 목록 |

- `G` `W`를 제외한 단축키는 Project 안에서만 동작합니다.
- 사용량과 Project 설정은 해당 메뉴를 볼 수 있는 역할에서만 동작합니다. 역할별 권한은 [멤버 권한](/docs/developers/member-roles)을 참고하세요.
- [커스텀 도메인](/docs/core-features/custom-domains)으로 접속한 경우 `G` `W`는 그 Workspace의 Project 목록으로 이동합니다.

---

## 콘텐츠 목록

테이블의 콘텐츠 목록 화면에서 동작합니다.

| 단축키 | 동작 |
| ------ | ---- |
| `C` | 새 콘텐츠 추가 (읽기 전용 테이블 제외) |
| `/` | 검색어 입력으로 이동 |

---

## 콘텐츠 편집

콘텐츠 편집 창이 열려 있을 때 동작합니다. 입력 중에도 사용할 수 있습니다.

| 단축키 | 동작 |
| ------ | ---- |
| `⌘ S` | 초안으로 저장 |
| `⌘ Enter` | 저장 후 발행 |

두 단축키 모두 버튼을 눌렀을 때와 같은 확인 창을 먼저 띄웁니다. 확인 창에서 확정해야 저장됩니다. 잠긴 콘텐츠이거나 콘텐츠를 편집할 권한이 없으면 동작하지 않습니다.

---

## 단축키가 동작하지 않을 때

- **입력 중**: `?`, `C`, `/`, `G`처럼 한 글자로 된 단축키는 입력란이나 에디터에 커서가 있으면 동작하지 않습니다. `⌘`와 함께 누르는 단축키는 입력 중에도 동작합니다.
- **창이 열려 있을 때**: 편집 창, 확인 창, 메뉴가 열려 있으면 한 글자 단축키가 동작하지 않습니다. `Esc`로 닫은 뒤 다시 누릅니다.
- **콘텐츠 편집 창이 열려 있을 때**: `⌘ B`는 에디터의 굵게 서식에 쓰이므로 사이드바를 접지 않습니다.

한글 입력 상태에서도 그대로 쓸 수 있습니다. 예를 들어 `G` `T`는 한글 상태에서 `ㅎ` `ㅅ` 자리의 키를 누르면 됩니다.
