# Column 타입

Table의 Column은 데이터 타입을 정의합니다. 타입에 따라 입력 방식, 저장 형식, API 응답 형태가 달라집니다.

---

## 타입 목록

### TEXT

텍스트 데이터를 입력합니다.

| 항목      | 값  |
| --------- | --- |
| 검색 가능 | 예  |
| 정렬 가능 | 예  |

예시 포맷

```json
"Hello Onttle"
```

옵션

| 옵션 키        | 옵션명       | 설명                                                                     |
| -------------- | ------------ | ------------------------------------------------------------------------ |
| `description`  | 설명         | 필드 설명을 입력하세요(선택 사항)                                        |
| `placeholder`  | 플레이스홀더 | 필드 플레이스홀더를 입력하세요(선택 사항)                                |
| `required`     | 필수         | 이 필드가 필수인지 여부를 설정합니다.                                    |
| `localization` | 다국어 지원  | 이 필드가 다국어 입력을 허용하는지 여부를 설정합니다.                    |
| `unique`       | 고유값       | 이 필드의 값이 테이블 내에서 고유해야 하는지 여부를 설정합니다.          |
| `multiple`     | Array        | Array 형태로 여러 텍스트 값을 동시에 입력할 수 있는지 여부를 설정합니다. |
| `textarea`     | Textarea     | 이 필드가 다중 행 입력을 허용하는지 여부를 설정합니다.                   |
| `allowHtml`    | HTML 허용    | 이 필드에 HTML 태그를 허용할지 여부를 설정합니다.                        |
| `defaultValue` | 기본값       | 텍스트 필드의 기본값을 설정합니다.                                       |
| `minText`      | 최소 길이    | 입력 가능한 텍스트의 최소 길이를 설정합니다.                             |
| `maxText`      | 최대 길이    | 입력 가능한 텍스트의 최대 길이를 설정합니다.                             |

### EDITOR

에디터로 HTML 또는 마크다운 형식으로 데이터를 입력합니다.

| 항목      | 값     |
| --------- | ------ |
| 검색 가능 | 예     |
| 정렬 가능 | 아니오 |

예시 포맷

```json
{ "type": "doc", "content": [] }
```

쓰기에는 두 가지 형식을 쓸 수 있고, REST API·대시보드·[MCP 서버](/docs/ai/mcp)가 모두 같은 형식을 받습니다.

| 쓰기 형식       | 예시                                                                              |
| --------------- | --------------------------------------------------------------------------------- |
| Markdown 문자열 | `"# 제목\n\n본문 **굵게**"`                                                       |
| TipTap 문서     | `{ "type": "doc", "content": [] }` 객체, 또는 이 객체를 직렬화한 JSON 문자열      |

```json
{
  "title": "새 글",
  "body": "# 제목\n\n본문 **굵게**"
}
```

Markdown은 저장할 때 TipTap 문서로 변환됩니다. 일반 텍스트도 Markdown으로 읽으므로 그대로 보낼 수 있습니다. 다국어 Column은 `{ "ko": 값, "en": 값 }`처럼 언어별로 같은 형식의 값을 보냅니다.

응답에는 저장된 문서와 렌더링된 형식이 함께 반환됩니다.

```json
{ "json": { "type": "doc", "content": [] }, "html": "…", "markdown": "…", "plain": "…" }
```

옵션

| 옵션 키        | 옵션명       | 설명                                                  |
| -------------- | ------------ | ----------------------------------------------------- |
| `description`  | 설명         | 필드 설명을 입력하세요(선택 사항)                     |
| `placeholder`  | 플레이스홀더 | 필드 플레이스홀더를 입력하세요(선택 사항)             |
| `localization` | 다국어 지원  | 이 필드가 다국어 입력을 허용하는지 여부를 설정합니다. |

### JSON

임의의 JSON 데이터를 입력합니다. 설정값, 메타데이터처럼 구조가 정해지지 않은 데이터에 적합합니다.

| 항목      | 값     |
| --------- | ------ |
| 검색 가능 | 예     |
| 정렬 가능 | 아니오 |

예시 포맷

```json
{ "theme": "dark", "tags": ["cms", "api"], "limit": 10 }
```

쓰기에는 두 가지 형식을 쓸 수 있고, REST API·대시보드·[MCP 서버](/docs/ai/mcp)가 모두 같은 형식을 받습니다.

| 쓰기 형식      | 예시                                                         |
| -------------- | ------------------------------------------------------------ |
| JSON 값        | `{ "theme": "dark" }`, `[1, 2, 3]`, `10`, `true`             |
| JSON 텍스트    | `"{\"theme\": \"dark\"}"` — 문자열은 JSON 텍스트로 읽습니다 |

문자열은 JSON 텍스트로 해석하므로, 올바른 JSON이 아니면 저장되지 않고 오류가 반환됩니다. JSON 문자열 값 자체(`"hello"`)를 저장하려면 `"\"hello\""`처럼 따옴표를 포함한 JSON 텍스트로 보냅니다.

응답에는 저장된 JSON 텍스트를 해석한 값이 반환됩니다.

```json
{ "settings": { "theme": "dark", "tags": ["cms", "api"], "limit": 10 } }
```

옵션

| 옵션 키        | 옵션명       | 설명                                                  |
| -------------- | ------------ | ----------------------------------------------------- |
| `description`  | 설명         | 필드 설명을 입력하세요(선택 사항)                     |
| `placeholder`  | 플레이스홀더 | 필드 플레이스홀더를 입력하세요(선택 사항)             |
| `required`     | 필수         | 이 필드가 필수인지 여부를 설정합니다.                 |
| `defaultValue` | 기본값       | 기본 JSON 값을 설정합니다. 올바른 JSON이어야 합니다.  |

## API 응답에서의 Column 값 형태

```json
{
  "data": {
    "title": "Onttle 소개",
    "view_count": 1024,
    "is_featured": true,
    "created_at": "2026-08-30T09:00:00.000Z",
    "thumbnail": {
      "id": "file_01hxk2",
      "url": "https://file.onttle.com/...",
      "name": "thumbnail.jpg",
      "size": 204800,
      "mimeType": "image/jpeg"
    }
  }
}
```
