# 멤버 권한

Workspace, Project 별 멤버의 권한에 따라 작업 권한이 제한됩니다. 권한 제어는 Front-end, Back-end 모두 확인을 합니다.

Front-end는 버튼을 disabled 처리하고 Sidebar Menu는 숨김(hide) 처리하며, Back-end는 권한이 없는 요청에 대해 error json을 반환합니다.

---

### Workspace Member Roles 종류

| ------ | ----------- |
