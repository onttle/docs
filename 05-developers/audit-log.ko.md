# Audit 로그

**Audit 로그**는 멤버·API 키·프로젝트·도메인·결제처럼 보안에 영향을 주는 변경을 **누가, 언제, 어디서** 했는지 기록합니다. **Workspace → 보안** 메뉴에서 확인하며, 팀원이 늘어나거나 외부 협업자가 참여할 때, 그리고 보안 점검이나 사고 조사 때 변경 이력을 추적하는 데 사용합니다.

이 문서를 읽고 나면 어떤 활동이 기록되는지, 기록을 어떻게 찾고 내보내는지, 플랜에 따라 얼마나 오래 보존되는지 알 수 있습니다.

---

## 누가 볼 수 있나요

Audit 로그는 [보안](/docs/developers/security) 메뉴 안에 있어 Workspace **소유자**(OWNER)와 **관리자**(ADMIN)만 볼 수 있습니다.

Audit 로그는 **Pro 요금제부터** 제공됩니다. Free 플랜에서는 활동이 기록되지 않으며 보안 메뉴에 업그레이드 안내가 표시됩니다. 플랜을 올리면 그 시점부터 기록이 시작되고, 플랜에 따라 [보존 기간](#보존-기간)이 달라집니다.

---

## 기록되는 활동

각 기록은 **실행자**(멤버 또는 시스템), **활동**, **대상**, **IP 주소와 브라우저 정보**, 활동별 **세부 정보**로 구성됩니다. 실행자의 이름과 이메일은 기록 시점 그대로 저장되므로 멤버가 이름을 바꾸거나 탈퇴해도 기록은 그대로 남습니다.

| 분류 | 기록되는 활동 |
| ---- | ------------- |
| 워크스페이스 | 정보 수정, 삭제, Audit 로그 CSV 내보내기 |
| 멤버 | 초대, 기존 회원 추가, 초대 수락으로 참여, 역할 변경, 내보내기, 나가기 |
| 초대 | 초대 역할 변경, 초대 취소 |
| 프로젝트 | 생성, 설정 수정, 삭제 |
| 프로젝트 멤버 | 추가, 역할 변경, 내보내기, 나가기 |
| API 키 | 생성, 수정, 활성화, 비활성화, 삭제 |
| 도메인 | 커스텀 도메인 추가·삭제, 대표 도메인 변경 |
| 테마 | 테마 변경 |
| 구독 | 요금제 변경, 해지 예약, 해지 취소 |
| 결제 수단 | 추가, 기본 결제 수단 변경, 삭제 |
| 보안 정책 | IP 허용·차단 목록 변경, 허용 이메일 도메인 변경, Audit 로그 켜기·끄기 |

세부 정보에는 역할 변경의 이전·이후 역할, API 키의 종류와 접두어, 요금제 변경의 대상 플랜처럼 활동을 이해하는 데 필요한 값만 담깁니다. **API 키 본문, 비밀번호, 카드 번호 같은 비밀 값은 기록되지 않습니다.**

> 콘텐츠, 번역, 변수 등 데이터 자체의 편집 이력은 Audit 로그가 아니라 각 Project의 버전 이력에서 확인합니다. 공개 API 호출 내역은 [사용량과 로그](/docs/usage-and-billing/usage-and-logs)를 참고하세요.

## Audit 로그 끄기

Audit 로그 카드 오른쪽 위의 **Audit 로그 사용** 스위치로 워크스페이스의 기록을 끄고 켤 수 있습니다. 소유자 또는 관리자 권한이 필요합니다.

- 끄면 새 활동은 기록되지 않습니다. 이미 기록된 활동은 보존 기간이 끝날 때까지 볼 수 있습니다.
- 끄는 순간은 `Audit 로그 끄기`로, 다시 켜는 순간은 `Audit 로그 켜기`로 기록되어 공백 구간을 알 수 있습니다.
- 다시 켜면 그 시점부터 기록됩니다. 꺼져 있던 동안의 활동은 복구되지 않습니다.

## 기록 찾기

목록은 최신 순으로 표시되며, 행을 클릭하면 액션 코드, 대상 ID, 브라우저 정보(User-Agent)와 세부 정보를 펼쳐 볼 수 있습니다.

| 필터 | 설명 |
| ---- | ---- |
| 기간 | 최근 1일, 1주, 30일, 90일 또는 날짜 직접 선택 |
| 분류 | 위 표의 분류 중 하나 |
| 실행자 | 현재 Workspace 멤버 중 한 명 |

필터는 주소에 함께 저장되므로 보고 있는 화면의 링크를 그대로 공유할 수 있습니다. 더 오래된 기록은 **더 보기**로 이어서 불러옵니다.

### CSV 내보내기

**CSV 내보내기**를 누르면 현재 필터에 해당하는 기록을 최신 순으로 최대 **5,000행**까지 내려받습니다. 파일에는 시간(UTC), 액션 코드, 실행자, 대상, 프로젝트, IP, 브라우저 정보, 세부 정보(JSON)가 포함됩니다.

- 내보내기 자체도 `워크스페이스 → Audit 로그 내보내기` 활동으로 기록됩니다.
- 수식으로 해석될 수 있는 셀은 스프레드시트에서 안전하게 열리도록 처리됩니다.

## 보존 기간

플랜별 보존 기간이 지난 기록은 매일 새벽(KST)에 자동으로 삭제됩니다. 보안 메뉴 상단에서 현재 플랜의 보존 기간을 확인할 수 있습니다.

| 플랜 | 보존 기간 |
| ---- | --------- |
| Free | 제공 안 함 |
| Pro | 7일 |
| Pro+ | 30일 |
| Ultra | 1년 |
| Enterprise | 무제한 |

- 조회와 내보내기는 보존 기간 안의 기록만 대상으로 합니다. 날짜를 직접 선택해도 보존 시작 시점 이전은 조회되지 않습니다.
- 플랜을 올리면 그 시점부터 더 오래 보존됩니다. 이미 삭제된 기록은 복구되지 않으므로, 장기 보관이 필요하면 주기적으로 CSV로 내보내 두세요.
- 플랜을 내리면 다음 정리 시점에 새 보존 기간을 넘긴 기록이 삭제됩니다. Free로 내리면 기록이 중단되고 남은 기록도 삭제됩니다.

## 권장 사용법

- **주기적으로 확인**: 멤버 역할 변경, Secret API 키 생성, 결제 수단 변경은 특히 눈여겨보세요.
- **외부 협업 종료 시**: 협업자가 나간 뒤 해당 멤버를 실행자로 필터해 남긴 변경을 점검합니다.
- **장기 보관**: 규정상 1년 이상 보관해야 한다면 월별로 CSV를 내보내 사내 저장소에 보관합니다.
