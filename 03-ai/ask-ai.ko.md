# Ask AI (Assistant)

Ask AI는 Project 대시보드 오른쪽에 붙는 AI 어시스턴트입니다. 자연어로 질문하면 현재 Project의 Table, Contents, 설정, 사용량을 직접 조회해 답하고, 변경이 필요한 작업은 미리보기 카드를 보여준 뒤 **승인한 경우에만** 실행합니다.

**사전 조건:** Project 멤버여야 합니다. 대화는 `AI.ASK.TOKENS` 메트릭으로 크레딧을 사용합니다. 변경 작업은 대시보드에서 직접 할 때와 같은 권한 검사를 거칩니다.

---

## 열기와 대화 관리

1. Project 화면 상단의 **Ask AI** 버튼을 클릭합니다. 패널이 오른쪽에 열리고 본문은 그만큼 줄어듭니다.
2. 빈 화면의 **빠른 프롬프트**를 누르거나 입력창에 질문을 적고 Enter를 누릅니다. 파일(이미지, CSV, 텍스트)을 첨부할 수도 있습니다.
3. 패널 헤더의 **새 채팅**으로 새 대화를 시작하고, **채팅 기록**에서 이전 대화를 다시 열거나 이름 변경·보관·삭제할 수 있습니다.

어시스턴트는 지금 보고 있는 Table과 **선택한 행**을 알고 있습니다. Contents 목록에서 행을 체크한 뒤 "선택한 행을 발행해줘"처럼 말하면 그 행이 대상이 됩니다.

---

## 두 가지 동작 방식

| 구분 | 동작 | 예 |
| ---- | ---- | -- |
| 바로 조회 | 질문 즉시 데이터를 읽어 답합니다. 데이터는 바뀌지 않습니다. | "어떤 테이블이 API로 쓰기 가능해?" |
| 승인 필요 | 변경 내용을 카드로 미리 보여주고 **승인**을 눌러야 실행합니다. **거절**하면 아무것도 바뀌지 않습니다. | "선택한 행 제목을 30자 이내로 다듬어줘" |

답변 위의 작은 마커가 어시스턴트가 어떤 조회를 했는지 보여줍니다(예: `콘텐츠 검색 중 · 31개 행 일치`). 마커가 빨간색이면 그 조회가 실패한 것이고, 어시스턴트는 보통 다른 방법으로 다시 시도합니다.

---

## 바로 조회할 수 있는 것

### 콘텐츠와 Table

| 할 수 있는 일 | 질문 예 |
| ------------- | ------- |
| Table과 컬럼, 카테고리 구조 | "이 프로젝트 테이블 목록을 요약해줘" |
| 조건에 맞는 행 검색, 행 전체 값 조회 | "최근 7일 안에 발행된 글만 찾아줘" |
| 행의 변경 이력과 두 버전 비교 | "이 행의 버전 1과 현재를 비교해서 바뀐 필드만 보여줘" |
| 변수와 번역(누락 언어 포함) | "누락된 언어가 있는 번역 키를 알려줘" |
| 프로젝트 점검 | "프로젝트 상태를 점검해서 문제점을 체크리스트로 알려줘" |

### 설정과 운영

| 할 수 있는 일 | 질문 예 |
| ------------- | ------- |
| Public API 설정(테이블별 엔드포인트, 임베딩·BM25, OpenAPI URL) | "어떤 테이블이 API로 읽기/쓰기 가능한지 보여줘" |
| OpenAPI 스펙 URL과 오퍼레이션 목록 | "OpenAPI 스펙에서 blogs 테이블 오퍼레이션만 보여줘" |
| API 레퍼런스와 클라이언트 코드 작성 | "이 테이블을 페이지네이션으로 가져오는 TypeScript 예제를 작성해줘" |
| API 키(마스킹), 멤버와 역할, Webhook 목록 | "API 키 현황과 멤버를 한 줄씩 요약해줘" |
| Webhook 전송 로그 | "문의 웹훅의 실패한 전송만 최근 5개 보여주고 원인을 추정해줘" |
| Agent 목록과 설정 | "에이전트가 어떤 모델과 지시문을 쓰는지 알려줘" |
| Vector 동기화 상태 | "테이블별 벡터 동기화 상태를 알려줘" |

### 파일

| 할 수 있는 일 | 질문 예 |
| ------------- | ------- |
| 파일 검색(종류, 크기, 업로드일) | "지난주에 올린 이미지 파일을 보여줘" |
| 임시 다운로드 링크(기본 5분 만료) | "가장 최근에 올린 로고 파일 링크를 줘" |
| 파일 사용처와 미사용 파일 | "어떤 행에서도 쓰지 않는 파일이 몇 개고 총 용량은 얼마야?" |
| 이미지·PDF 텍스트 추출(OCR) | "스캔한 계약서 파일의 텍스트를 추출해줘" |

OCR은 업로드할 때 추출해 둔 텍스트가 있으면 크레딧 없이 바로 보여주고, 없으면 그 자리에서 실행하며 `FILE.OCR.CALLS` 1회가 기록됩니다.

### 크레딧, 로그, 문서

| 할 수 있는 일 | 질문 예 |
| ------------- | ------- |
| 크레딧 잔액과 결제 주기 사용량 | "이번 결제 주기 크레딧 사용량을 요약해줘" |
| 비용 추정 | "Docs 31개 행을 전부 임베딩하면 크레딧이 얼마나 들어?" |
| API 로그 분석(요청 수, 오류, 경로, 키별 비교) | "최근 7일 API 로그를 분석해줘" |
| Onttle 공식 문서 검색 | "Webhook 설정 방법을 문서에서 찾아줘" |

문서 질문에는 답변 아래에 번호가 붙은 **출처** 목록이 표시되고, 각 항목은 해당 문서 섹션으로 연결됩니다. 답변 안의 `[1]`, `[2]`가 그 번호입니다.

## 승인이 필요한 작업

| 작업 | 설명 |
| ---- | ---- |
| 목록 필터 | 보고 있는 Contents 목록에 필터·정렬을 적용합니다. 데이터는 바뀌지 않아 바로 적용됩니다. |
| Table 설계, 컬럼 추가·수정 | 새 Table 제안, 기존 Table에 컬럼 추가, 컬럼 이름·옵션 변경. 컬럼 타입은 바꿀 수 없습니다. |
| Table 수정 | 이름, slug, 설명, 읽기 전용 변경 |
| 행 생성·수정·삭제 | 붙여넣은 텍스트나 CSV 임포트, 선택한 행 일괄 수정, 삭제. 잠긴 행은 건너뜁니다. |
| Table 콘텐츠 모두 삭제 | 한 Table의 잠기지 않은 모든 행을 삭제합니다(truncate). 카드에 삭제될 행 수가 표시되며, 소유자와 관리자만 실행할 수 있고 되돌릴 수 없습니다. |
| 발행·잠금·복원 | 발행/발행 취소/보관, 잠금/해제, 이전 버전으로 복원 |
| Table 콘텐츠 모두 발행·발행 취소 | 한 Table의 발행되지 않은 모든 행을 발행하거나, 발행된 모든 행을 초안으로 되돌립니다. 카드에 변경될 행 수가 표시되며, 잠긴 행은 건너뛰고 보관된 행은 발행하지 않습니다. |
| 카테고리·변수·번역 | 샘플 생성, 값 수정, 카테고리 값 추가·이름 변경·삭제, 변수 복원 |
| API 설정 | 테이블 엔드포인트 켜기/끄기, 임베딩·BM25, OpenAPI URL |
| Webhook 생성 | URL, 대상 Table, 이벤트(CREATED, UPDATED, DELETED) |

카드에는 변경 전·후 값, 대상 행 수, 삭제처럼 되돌릴 수 없는 작업의 경고가 함께 표시됩니다. 실행이 끝나면 적용된 수와 실패한 수가 같은 카드에 남습니다.

### AI 생성은 두 단계로 승인합니다

빈 셀 채우기, 샘플 행 생성, 번역 채우기를 AI에 맡기면 다음 순서로 진행됩니다.

1. **생성 승인**: "AI 크레딧이 사용됩니다"라는 카드가 뜹니다. 승인하면 값을 생성만 하고 저장하지 않습니다.
2. **저장 승인**: 생성된 값이 행 수정·행 생성·번역 수정 카드에 변경 전·후로 표시됩니다. 여기서 승인해야 저장됩니다.

몇 개 셀 정도는 어시스턴트가 직접 값을 써서 바로 저장 카드를 보여주고, 행이 많거나 "AI로 채워줘"라고 하면 위 두 단계를 거칩니다. 생성 단계는 `AI.GENERATION.TOKENS`를 사용합니다.

## 빠른 프롬프트

새 채팅의 빈 화면에는 자주 쓰는 요청이 버튼으로 준비되어 있습니다. 행을 선택한 상태면 선택한 행에 대한 항목이 먼저 보입니다.

- 목록 필터, 테이블 설계, 일괄 수정, 행 임포트
- 샘플 카테고리·변수·번역, 누락 번역 채우기, SEO 항목 채우기
- API 코드, 로그 설명, 크레딧과 사용량, 프로젝트 점검
- 문서에 질문하기
- (행 선택 시) 선택한 행의 빈 칸 채우기, 수정, 발행, 삭제, 변경 이력

---

## 잘 쓰는 요령

- **Table 이름이나 slug로 말하세요.** "docs 테이블에서…"처럼 적으면 어시스턴트가 알아서 찾습니다. 여러 Table이 있을 때는 어느 Table인지 되묻습니다.
- **행은 체크해 두고 말하세요.** "선택한 행"이 가장 정확합니다.
- **한 번에 하나의 주제.** 조회와 변경을 한 질문에 섞으면 변경 카드가 뒤로 밀릴 수 있습니다.
- **승인 전에 카드를 확인하세요.** 어시스턴트는 승인 결과가 돌아오기 전에는 "변경했다"고 말하지 않습니다.

## 사용량과 한도

| 사용 | 메트릭 |
| ---- | ------ |
| Ask AI 대화 | `AI.ASK.TOKENS` |
| AI 생성(빈 셀, 샘플 행, 번역 채우기) | `AI.GENERATION.TOKENS` |
| OCR 실행 | `FILE.OCR.CALLS` |

크레딧이 부족하면 대화가 시작되지 않고 안내가 표시됩니다. 변경 이력·복원은 버전 기록이 포함된 플랜에서만 동작합니다.

---

## 주의 사항

- AI 답변에는 오류가 있을 수 있습니다. 숫자와 설정 값은 카드와 대시보드 화면으로 확인하세요.
- 질문과 조회 결과는 AI 모델에 전달됩니다. 개인 식별 정보, 결제 정보, 비밀번호나 토큰이 들어 있는 컬럼은 질문 대상에서 빼세요.
- API 키는 항상 마스킹된 형태(접두사와 마지막 4자리)로만 표시되며, 어시스턴트는 전체 키를 보여주지 않습니다.
